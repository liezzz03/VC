# Descripción del trabajo

Este repositorio contiene una serie de ejercicios prácticos realizados en Python utilizando la biblioteca OpenCV, enfocados en el procesamiento y manipulación de imágenes. Las tareas desarrolladas incluyen:

- Generación de un tablero de ajedrez en escala de grises (sin y con uso de IA).
- Creación de una imagen estilo Mondrian.
- Detección de los píxeles más claros y más oscuros, y marcarlos con círculos.
- Propuesta creativa de estilo Pop Art, generando un collage con variaciones de color.

Cada celda del [cuaderno](/p1/P1_Tareas.ipynb) está comentada para explicar su propósito y facilitar la comprensión del código.
